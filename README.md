# jpatinoe.github.io

The personal site of Juan Patiño-Echeverría, built with Jekyll on GitHub Pages.

- Content lives in `_data/`: `research.yml`, `teaching.yml`, `cv.yml`, `destinations.yml` (the four links on the home page's field) and `nav.yml` (the bar). Contact details are in `_config.yml`.
- Pages: `index.html` (home), `research.html`, `teaching.html`, `cv.html`, `404.html`. Old addresses (/projects/, /about/, /contact/) redirect.
- Look and behaviour: `assets/site.css` and `assets/site.js` (the field, the bar, the switches and the list reveal); the colours are set in `_includes/head.html`. The design system is the reference for both.
- The teaching applets (`phase-plane.html`, `phase-portrait.html`, `quadrature-explorer.html`, `team-allocator.html`) keep their addresses.
